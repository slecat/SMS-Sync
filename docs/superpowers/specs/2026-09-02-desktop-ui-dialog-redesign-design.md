# 桌面端双栏与稳定弹窗设计规格

**目标**：让桌面端采用与移动端一致的暖灰/墨绿卡片语言，使用稳定的双栏工作区，并消除弹窗重复创建、关闭竞态和焦点抢占。

## 范围

- 左侧固定导航：同步、连接、设置、诊断。
- 右侧消息工作区：连接状态、在线设备、可滚动消息列表、读取最新和发送测试。
- 弹窗继续使用 Electron 独立窗口，但由单实例服务复用；消息更新只更新当前窗口内容。
- 弹窗加载失败回退系统通知；复制验证码通过 IPC 完成。

## 视觉规则

- 背景 `#F4F1EB`，主色 `#173C36`，强调色 `#007F73`，卡片 `#FFFDF9`，边框 `#DDD9D1`。
- 统一 12/16/22px 圆角层级、清晰边框和低强度阴影；移除深色弹窗、蓝色渐变和装饰性 AI 文案。
- 使用系统字体栈，正文最小 13px，正文对比度满足 WCAG AA。

## 弹窗稳定性

`InAppAlertService` 保存 `alertWindow` 和递增的窗口 token。创建、加载、定时关闭、`closed` 回调都校验 token；重复消息只调用 `loadURL` 更新当前窗口。窗口销毁、导航异常、复制失败均捕获并记录，必要时调用注入的系统通知回退。窗口使用 `showInactive`，不抢焦点；Esc 和关闭按钮走统一 `closeAlert`。

## 验收

- 连续触发 20 条消息只存在一个弹窗窗口，最终内容为最后一条。
- 自动关闭旧窗口不会关闭新窗口；复制失败不影响后续消息。
- 主界面在 1024px、1440px 宽度下无横向滚动，消息列表内部滚动。
- 桌面测试、lint 和 Windows 打包全部通过。
